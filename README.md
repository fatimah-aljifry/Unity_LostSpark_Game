# Unity_LostSpark_Game
Lost Spark – Unity Game

 Overview

Lost Star is a 3D space exploration game developed in Unity, where players control a lost star navigating between planets in search of its family.
 Gameplay

The player travels through space and visits different planets. On Venus, the core challenge takes place:

Collect hidden treasures
Avoid meteor obstacles
Complete objectives within a time limit

Technologies
Unity (Game Engine)
C# (Scripting)
Blender (3D Assets)
Java (Custom object integration)
